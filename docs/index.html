Get started

Running in under a minute.

Awaiting approval on the Chrome Web Store. One-click install is coming — until then, the manual install below takes about 30 seconds.
  1. Download the .zip and unzip it.
  2. Open chrome://extensions and turn on Developer mode (top right).
  3. Click Load unpacked and select the folder containing manifest.json.
  4. Stay logged in to X, click the toolbar icon, hit Refresh — your numbers appear.

X Goals reads x.com/i/account_analytics in your own browser session. Nothing is uploaded, nothing is proxied, nothing is sold. The source is right there — audit it yourself.
